# Roadmap

1. **Two Sum in Go (current):** read the existing reasoning, implement brute force
   independently, pass the tests, and explain correctness and time/space costs.
2. **Revisit Two Sum:** explore an optimization only after the first implementation
   works; explain its trade-offs and do an independent retry.
3. **Choose the next problem together:** continue arrays and hashing before moving
   to two pointers, sliding windows, stacks, binary search, and recursion.

Create only the current exercise and its branch. Use Go by default; the shared runner also accepts other languages.
